# Open Source — IGNOU

**Learn together. Build together. Contribute together.**

Welcome to **Open Source — IGNOU**, an independent, student-led community for learners interested in programming, open-source software, and building useful things together.

Whether you're writing your first line of code or already maintaining projects, there's a place for you here.

## What we're here for

- 💻 **Build projects** — collaborate on practical, student-friendly open-source projects.
- 📚 **Learn in public** — share notes, tutorials, documentation, and useful resources.
- 🤝 **Help each other** — ask questions, review contributions, and learn from feedback.
- 🌱 **Make your first contribution** — documentation, typo fixes, tests, design, and bug reports all count.

## Explore the organization

- **[Browse our repositories](https://github.com/ignouos?tab=repositories)** — explore projects and code.
- **[Find issues](https://github.com/orgs/ignouos/issues)** — discover bugs, ideas, and ways to contribute.
- **[Open Source Guides](https://opensource.guide/how-to-contribute/)** — learn how to contribute.
- **[GitHub Pull Request Guide](https://docs.github.com/en/pull-requests)** — learn how to propose changes.

## How to contribute

1. Explore the repositories and read the project's README.
2. Look for issues labelled `good first issue` or `help wanted`.
3. Ask questions if you need clarification.
4. Fork the repository and create a branch.
5. Make your changes, test them, and open a pull request.
6. Be respectful and open to feedback.

**New to Git or open source?** That's completely fine. Start small, ask questions, and learn as you go.

## Our principles

- **Open learning:** share knowledge and help others grow.
- **Respect:** welcome contributors and communicate constructively.
- **Accessibility:** make projects and documentation easier to use.
- **Transparency:** communicate clearly about project status.
- **Community over competition:** we improve by building together.
